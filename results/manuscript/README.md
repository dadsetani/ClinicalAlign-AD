# Stage 4: manuscript assets

The aggregate CSV files in this directory and the LaTeX tables under `tables/`
are generated by:

    python scripts/04_make_manuscript_assets.py

The script also creates:

- `figures/reproducible_workflow.png`
- `figures/modality_coverage.png`
- `figures/heldout_auc_ablation.png`

No participant identifiers are included in these outputs. Structural-MRI
results are marked exploratory in both the tables and manuscript.
